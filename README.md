# Sound Displayer

A real-time audio visualization application that transforms sound into animated geometric patterns.

## Features

- Real-time audio visualization
- Desktop audio and microphone input
- Multiple visualization styles, including Vortex, Cymatics, and Rosette
- Interactive visual effects
- Browser-based HTML application
- Windows launcher included

## Getting Started

1. Download the project files using **Code → Download ZIP**.
2. Extract the downloaded ZIP file.
3. Open the `Sound Displayer V3.6.9` folder.
4. Follow the included instructions to launch the application.

## Version

Current version: **3.6.9**

## About

Sound Displayer is an experimental audio visualization project exploring the relationship between sound, geometry, and animated visual effects.
